# adr — Architecture Decision Records

Format: `ADR-NNN-kurzer-titel.{yaml,ai.json,md}`. Jede groessere
Architekturentscheidung bekommt ein ADR, bevor sie in `03_Architektur/`,
`04_Programme/` oder `05_Hilfsprogramme/` als `accepted` landen kann
(Regel 3). Niemals nachtraeglich aendern — neue Entscheidung = neues ADR
mit Verweis auf das alte (`supersedes`).
